# Aura v1 — ИИ-помощник для Windows

Трей-приложение: **Win+Shift+Z** → оверлей «Aura» у края экрана:
1. **Найти и нажать** — UIA-поиск кнопок активного окна, подсветка, «Нажать» (1 с «Делаю» + Стоп), **«Запомнить»**.
2. **Выученные кнопки** (v0.4.0) — список (имя · тип · процесс), Удалить / Очистить всё, «● Учусь», «действовать».

Индикатор «Смотрю · <app>» виден всё время, пока открыт оверлей; **Пауза** — в индикаторе и в трее (при паузе контекст не читается вообще).

## v0.5.0 — мега-спринт
- **Двойной клик / ПКМ**: у каждой выученной кнопки поле `Action` (Click / DoubleClick / RightClick); выбор в комбо рядом с «Запомнить» (если в списке выбрана кнопка — меняет её действие). «Нажать», «действовать», «Серия», ИИ используют это действие. Клик — только `SendInput` после «Делаю» 1 с + Стоп.
- **🖱 Под курсором (Win+Shift+X)** — обучение по клику **без хуков**: наводишь мышь на кнопку и жмёшь хоткей (или кнопку в оверлее / трее — запомню через 3 с). Один `AutomationElement.FromPoint`; если UIA пусто и включён OCR — OCR маленькой области 360×120 вокруг курсора (в памяти).
- **🖼 запомнить картинку** (opt-in, выкл. по умолчанию): при запоминании сохраняю PNG кнопки ≤120×60 в `%AppData%\Aura\templates\{Id}.png` — **единственная** картинка, которую Aura пишет на диск, и только по галочке. «действовать» (с OCR opt-in) ищет её в снимке активного окна (в памяти, SAD), если ни UIA, ни OCR не нашли.
- **⚡ При старте** (opt-in): список «Запустить .exe / Открыть URL / Нажать выученную / Ждать». Через 2 с после запуска Aura; клики с «Делаю». Кнопка «▶ Проверить сейчас».
- **⏩ Серия** — все выученные кнопки активного окна по порядку (пауза между шагами `StepDelayMs`, по умолчанию 800 мс).
- **🤖 ИИ** — как в circuit-sim: OpenAI-совместимый чат через бесплатный Groq-прокси `https://circuit-sim-ai-proxy.vercel.app/v1` (`openai/gpt-oss-20b`, ключ в приложении не нужен) или локальный Ollama `http://127.0.0.1:11434/v1`. Галочка **«ИИ (сеть)»** — единственное, что разрешает сеть (выкл. по умолчанию). Отправляю: приложение, заголовок, имена выученных кнопок, запрос; текст окна (OCR) — только с «приложить текст окна». Ответ ИИ → команды `CLICK / DOUBLECLICK / RIGHTCLICK / FIND / REMEMBER / LAUNCH / OPEN / WAIT` → список с галочками → «Выполнить отмеченные» (клики с «Делаю» 1 с).
- **Hack INFO fix**: «действовать» больше не делает OCR с пустым запросом — один снимок, ищу только точные имена выученных OCR-кнопок.
- Трей: «Действовать», «ИИ (сеть)», «Запомнить под курсором». Версия в оверлее. Звук клика — `ClickSound` в settings.json.

- ИИ знает список твоих «При старте → Запустить» программ и правил; подсказка ИИ про LAUNCH приведена в соответствие с ограничениями 0.5.5.
- Профили: кнопки текущего приложения наверху списка, флажок «только <app> (k из n)».

- Индикатор показывает «ищу: картинка/текст «X»…», пока идёт OCR или поиск по картинке — захват экрана никогда не бывает незаметным.
- «Стоп» на индикаторе теперь останавливает и всю серию (как «⏹ Стоп всё» в трее).

- 🚫 «Не трогать» в оверлее: один список 🔒 исключённых (Aura не читает и не жмёт) и ✋ «не действовать» приложений; добавить текущее / по имени, убрать.

- 💡 Правила «вижу X → предложить Y» (`%AppData%\Aura\rules.json`). Только подсказки: при открытии Aura сработавшие правила показываются с кнопкой «▶ Сделать предложенное» (через «Делаю» 1 с + Стоп, с защитой «ушёл из окна»).
- Опция «подсказывать в фоне» (выкл. по умолчанию): раз в 3 с одно чтение UIA активного окна (без снимков экрана), только тост, не чаще раза в 60 с на правило. Исключения и Пауза останавливают.

- Трей: «⏹ Стоп всё» — мгновенно отменяет текущий «Делаю» и все оставшиеся шаги серии / «При старте» / ИИ-чеклиста.
 (безопасность, по замечаниям Hack/Formal)
- OPEN: только корректные http/https ссылки (без логина в URL, без пробелов); иначе отказ с тостом.
- LAUNCH: только существующий .exe/.bat/.cmd по полному локальному пути, без `..`, UNC и схем. ИИ может запускать **только** программы, которые ты сам добавил в «При старте → Запустить». В списке ИИ-действий виден полный путь и пометка ⛔, если будет отказ.
- Ключ ИИ больше не хранится открытым текстом: в settings.json только `AiKeyProtected` (DPAPI, текущий пользователь). Старый `AiKey` шифруется и удаляется при запуске. Для Groq-прокси ключ не нужен.

- Трей: «Экспорт кнопок…» / «Импорт кнопок…» — JSON (имена, действия, позиции; без картинок). Импорт добавляет только новые.

- ИИ «Выполнить отмеченные» и «Серия»: если ты ушёл в другое приложение, клик не выполняется (тост «Ты ушёл из окна»). Остальные пункты отменяются с понятной записью.
- «Серия» продолжает работать, даже если закрыть оверлей, и всегда заканчивается тостом «Серия: k из n» (с причиной остановки).
- «Под курсором»: физические координаты курсора (high-DPI / несколько мониторов).

- Профили: «не действовать в этом приложении» (по процессу) и «вкл/выкл» для каждой выученной кнопки.

- Картинки: сначала ищу в запомненном месте (±24 px, маленький снимок), потом по всему окну с грубым шагом 1/4 → уточнение. Заметно быстрее.
- «При старте»: поле «Пауза между шагами, мс» (200–10000) и «звук клика».
- ИИ: история чата (последние 8 сообщений, только в памяти) + «Новый чат»; ответы с прокруткой.
 (PC Bot, DESKTOP)
Нужен .NET 8 SDK.
```powershell
cd src\Aura
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
New-Item -ItemType Directory -Force $env:USERPROFILE\Apps\Aura | Out-Null
Copy-Item publish\Aura.exe $env:USERPROFILE\Apps\Aura\ -Force
& $env:USERPROFILE\Apps\Aura\Aura.exe
```
Автозагрузка (по желанию): ярлык на `Aura.exe` в `shell:startup`.

## Данные
- Настройки: `%AppData%\Aura\settings.json` — `Paused`, `ScreenCaptureOptIn` (по умолчанию `false`), `ExcludedApps`, `ActOptIn` (по умолчанию `false`).
- Выученные кнопки: `%AppData%\Aura\buttons\buttons.json` (Process, Name, AutomationId, Type). Старые `macros\` больше не используются.

## Приватность (Hack Formal)
- Хоткей через `RegisterHotKey` — **никаких** `SetWindowsHookEx`, кейлоггера, хуков мыши.
- Контекст читается **один раз по нажатию** хоткея: `GetForegroundWindow`, `GetWindowText`, `GetWindowThreadProcessId`.
- Буфер обмена не читается. Скриншот/OCR — только opt-in (см. v0.2.2), по умолчанию ничего не снимается.
- Сеть — только при включённом «ИИ (сеть)» и нажатии «Спросить». Приложения из `ExcludedApps` (менеджеры паролей) — заголовок скрыт.

Дизайн-референс: `src/Aura/Assets/overlay-v1.design.html` (Design Formal v1).

## Хоткей и открытие без хоткея (v0.1.2)
- По умолчанию **Win+Shift+Z**. Если занят — Aura пробует **Win+Ctrl+A**, затем **Win+Alt+Z**; какой взялся — покажет уведомление и подсказка в трее/оверлее.
- Если все заняты — Aura работает из трея: **левый клик по иконке** или «Открыть».
- Из внешнего инструмента: `Aura.exe --open` (при запущенной Aura) или Set именованного события `Local\Aura.OpenOverlay`.

## OCR-фолбэк (v0.2.2)
- Движок: **Windows.Media.Ocr** (встроенный WinRT OCR Windows 10/11, офлайн). Сборка `net8.0-windows10.0.19041.0` (C#/WinRT-проекции в self-contained exe, MSIX/упаковка **не нужна**). Нужен установленный язык Windows с OCR (ru/en обычно есть); если нет — Aura пишет «OCR недоступен…» и ничего не снимает.
- Включение: галочка **«OCR если UIA не нашёл»** в карточке «Найти и нажать» (или пункт в трее). По умолчанию **выкл.** (`ScreenCaptureOptIn=false`).
- Когда работает: только после «Найти», только если UIA вернул пусто, **один раз** на поиск, только при открытом оверлее, не на паузе, не для `ExcludedApps`. Индикатор «Делаю: OCR» на время распознавания.
- Снимок: только прямоугольник активного окна (`GetWindowRect` + `CopyFromScreen`) в память → `SoftwareBitmap` → распознавание → буфер очищается и освобождается. На диск/в лог не пишется. Строки внутри самого оверлея отбрасываются.
- Результат: строки/слова с рамками → тот же список, та же оранжевая подсветка, клик **только** после «Нажать» (1 с «Делаю» + Стоп/Esc) в центр рамки. Авто-клик по-прежнему выключен.

## Выученные кнопки и «действовать» (v0.4.0)
Заменяет макросы v0.3 и карточки «Что на экране / Следующий шаг / Готовое действие» (удалены).
- **Учусь только через Aura.** Кнопка запоминается, когда ты выбрал её в «Найти» и нажал **«Запомнить»**, или нажал **«Нажать»** при включённом «● Учусь» (красная точка в индикаторе). Свои клики мышью вне Aura **не отслеживаются**: `SetWindowsHookEx` / `WH_MOUSE_LL` / кейлоггер **не используются**.
- Пустые имена и OCR-результаты не запоминаются; приложения из `ExcludedApps` — тоже.
- **«действовать»** (opt-in, выкл. по умолчанию): каждые 2 с одно UIA-чтение **только активного окна** (без OCR, без снимков экрана). Совпадение с выученной кнопкой этого процесса (AutomationId+Name+Type, иначе Name+Type) → индикатор «Делаю · <кнопка>» 1 с со **Стоп** (и Esc в оверлее, Пауза) → один клик. Если окно сменилось за эту секунду — не жмёт. Повтор той же кнопки в том же окне — не раньше чем через 15 с.
- Пауза и исключения останавливают и скан, и клик. Индикатор «Смотрю · <app> · действую» виден всё время, пока «действовать» включено.
- Сеть, буфер обмена, запись скриншотов на диск — нет.

## v0.4.1 — OCR-кнопки и мелкий текст
- «Запомнить» работает и для OCR-результатов (кнопки без UIA, напр. «Войти» в Crossout): сохраняются только имя, процесс и рамка (тип OCR) — никаких картинок на диске. В списке помечены «OCR».
- Мелкий текст: снимок окна (только в памяти) увеличивается в 2× перед распознаванием; крошечные рамки слов расширяются до ~40×24 для надёжного клика.
- «Действовать» использует OCR **только** если включены и «действовать», и «OCR если UIA не нашёл», только для OCR-выученных имён, только активное окно, при видимом «Смотрю»; один снимок в память за проход, затем «Делаю» 1 с + Стоп → клик. Пауза 15 с на кнопку. Хуков нет (SetWindowsHookEx не используется).

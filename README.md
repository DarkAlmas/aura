# Aura v1 — ИИ-помощник для Windows

Трей-приложение: **Win+Shift+Z** → оверлей «Aura» у края экрана:
1. **Найти и нажать** — UIA-поиск кнопок активного окна, подсветка, «Нажать» (1 с «Делаю» + Стоп), **«Запомнить»**.
2. **Выученные кнопки** (v0.4.0) — список (имя · тип · процесс), Удалить / Очистить всё, «● Учусь», «действовать».

Индикатор «Смотрю · <app>» виден всё время, пока открыт оверлей; **Пауза** — в индикаторе и в трее (при паузе контекст не читается вообще).

## Сборка (PC Bot, DESKTOP)
Нужен .NET 8 SDK.
```powershell
cd src\Aura
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
New-Item -ItemType Directory -Force $env:USERPROFILE\Apps\Aura | Out-Null
Copy-Item publish\Aura.exe $env:USERPROFILE\Apps\Aura\ -Force
& $env:USERPROFILE\Apps\Aura\Aura.exe
```
Автозагрузка (по желанию): ярлык на `Aura.exe` в `shell:startup`.

## Данные
- Настройки: `%AppData%\Aura\settings.json` — `Paused`, `ScreenCaptureOptIn` (по умолчанию `false`), `ExcludedApps`, `ActOptIn` (по умолчанию `false`).
- Выученные кнопки: `%AppData%\Aura\buttons\buttons.json` (Process, Name, AutomationId, Type). Старые `macros\` больше не используются.

## Приватность (Hack Formal)
- Хоткей через `RegisterHotKey` — **никаких** `SetWindowsHookEx`, кейлоггера, хуков мыши.
- Контекст читается **один раз по нажатию** хоткея: `GetForegroundWindow`, `GetWindowText`, `GetWindowThreadProcessId`.
- Буфер обмена не читается. Скриншот/OCR — только opt-in (см. v0.2.2), по умолчанию ничего не снимается.
- Сеть не используется. Приложения из `ExcludedApps` (менеджеры паролей) — заголовок скрыт.

Дизайн-референс: `src/Aura/Assets/overlay-v1.design.html` (Design Formal v1).

## Хоткей и открытие без хоткея (v0.1.2)
- По умолчанию **Win+Shift+Z**. Если занят — Aura пробует **Win+Ctrl+A**, затем **Win+Alt+Z**; какой взялся — покажет уведомление и подсказка в трее/оверлее.
- Если все заняты — Aura работает из трея: **левый клик по иконке** или «Открыть».
- Из внешнего инструмента: `Aura.exe --open` (при запущенной Aura) или Set именованного события `Local\Aura.OpenOverlay`.

## OCR-фолбэк (v0.2.2)
- Движок: **Windows.Media.Ocr** (встроенный WinRT OCR Windows 10/11, офлайн). Сборка `net8.0-windows10.0.19041.0` (C#/WinRT-проекции в self-contained exe, MSIX/упаковка **не нужна**). Нужен установленный язык Windows с OCR (ru/en обычно есть); если нет — Aura пишет «OCR недоступен…» и ничего не снимает.
- Включение: галочка **«OCR если UIA не нашёл»** в карточке «Найти и нажать» (или пункт в трее). По умолчанию **выкл.** (`ScreenCaptureOptIn=false`).
- Когда работает: только после «Найти», только если UIA вернул пусто, **один раз** на поиск, только при открытом оверлее, не на паузе, не для `ExcludedApps`. Индикатор «Делаю: OCR» на время распознавания.
- Снимок: только прямоугольник активного окна (`GetWindowRect` + `CopyFromScreen`) в память → `SoftwareBitmap` → распознавание → буфер очищается и освобождается. На диск/в лог не пишется. Строки внутри самого оверлея отбрасываются.
- Результат: строки/слова с рамками → тот же список, та же оранжевая подсветка, клик **только** после «Нажать» (1 с «Делаю» + Стоп/Esc) в центр рамки. Авто-клик по-прежнему выключен.

## Выученные кнопки и «действовать» (v0.4.0)
Заменяет макросы v0.3 и карточки «Что на экране / Следующий шаг / Готовое действие» (удалены).
- **Учусь только через Aura.** Кнопка запоминается, когда ты выбрал её в «Найти» и нажал **«Запомнить»**, или нажал **«Нажать»** при включённом «● Учусь» (красная точка в индикаторе). Свои клики мышью вне Aura **не отслеживаются**: `SetWindowsHookEx` / `WH_MOUSE_LL` / кейлоггер **не используются**.
- Пустые имена и OCR-результаты не запоминаются; приложения из `ExcludedApps` — тоже.
- **«действовать»** (opt-in, выкл. по умолчанию): каждые 2 с одно UIA-чтение **только активного окна** (без OCR, без снимков экрана). Совпадение с выученной кнопкой этого процесса (AutomationId+Name+Type, иначе Name+Type) → индикатор «Делаю · <кнопка>» 1 с со **Стоп** (и Esc в оверлее, Пауза) → один клик. Если окно сменилось за эту секунду — не жмёт. Повтор той же кнопки в том же окне — не раньше чем через 15 с.
- Пауза и исключения останавливают и скан, и клик. Индикатор «Смотрю · <app> · действую» виден всё время, пока «действовать» включено.
- Сеть, буфер обмена, запись скриншотов на диск — нет.
